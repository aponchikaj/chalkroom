# Scene builder conventions

How to build a scene for the Chalkroom Live film. Read `PLAN.md` (the spec for your scene),
`../DESIGN.md` (the look), then this file. `compositions/s04-reveal.html` is the finished
reference scene: copy its structure.

Everything here was verified by snapshot on HyperFrames 0.8.169 (2026-10-18).

## 1. File layout

```
video/
  index.html               root film: mounts the 12 scenes, subtitles, grain overlay, audio
  script.json              scene windows and subtitle cues (film seconds). Do not edit casually.
  PLAN.md                  director's plan, per-scene spec
  CONVENTIONS.md           this file
  VOICEOVER.md             Georgian voice script with timecodes and English gloss
  subtitles.ka.srt         generated
  compositions/
    s01-alone.html ... s12-end.html   one file per scene (yours)
    subtitles.html         generated by tools/build-subs.mjs, never edit
  assets/
    chalk.css              tokens, fonts, components (the kit CSS)
    kit.js                 motion helpers (window.Kit)
    fonts/*.woff2          self-hosted fonts (latin + georgian subsets)
    vendor/gsap.min.js     GSAP 3.14.2, local (no network at render)
  audio/
    music.wav, sfx.wav     stems (audio pass)
    cues/<sceneId>.json    SFX cue list that each scene ships
  tools/build-subs.mjs     script.json -> subtitles.html + subtitles.ka.srt
  snapshots/, renders/, .hyperframes/   generated, git-ignored
```

You own only `compositions/<your-id>.html` and `audio/cues/<your-id>.json`. Do not edit
`index.html`, `assets/*`, `script.json` or other scenes; ask the kit owner for kit changes.

## 2. Commands (all verified)

Always set `HYPERFRAMES_SKIP_SKILLS=1`, never run `hyperframes skills`, and run at most one
Chrome command (check/snapshot) at a time: the machine has 8 GB. Never run a full render
while building scenes. Run from `video/`.

```bash
# lint + runtime + layout + contrast for the whole film (about 12 s)
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest check

# check only your scene window, including every tween start/end
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest check --range 50,64 --at-transitions --max-transition-samples 40

# snapshot your scene at exact FILM times (scene start + local time); --no-end skips the film's last frame
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest snapshot --at 50.0,51.2,55,58.4,63.9 --no-end -o snapshots/s06

# or N evenly spaced frames across your scene
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest snapshot --composition s06-lesson --frames 6 --no-end -o snapshots/s06

# zoom into a detail (selector or x,y,w,h) at 3x density
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest snapshot --at 55 --no-end --zoom ".s06-board" -o snapshots/s06-zoom

# static lint only (fast, no browser)
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest lint

# list compositions and durations
HYPERFRAMES_SKIP_SKILLS=1 npx -y hyperframes@latest compositions

# rebuild subtitles after editing script.json cues
node tools/build-subs.mjs
```

Snapshots write PNGs plus `contact-sheet*.jpg` into the `-o` folder. **Look at the PNGs.**
Snapshot one scene by passing film times; the whole film loads (about 10 s per run).

Gate for every scene before hand-in: `check` passes with 0 errors; snapshots at start,
middle, end and both boundaries (start + 0.05, end - 0.05) look right; no text in the bottom
170 px band; no tofu; handoff frames match the neighbours.

## 3. Scene file structure

A scene file is exactly one bare `<template>` fragment (no doctype, html, head or body).
All `<link>`, `<style>` and `<script>` go inside it.

```html
<template id="s06-lesson-template">
  <div data-composition-id="s06-lesson" data-width="1920" data-height="1080" data-duration="14">
    <link rel="stylesheet" href="../assets/chalk.css" />
    <script src="../assets/vendor/gsap.min.js"></script>
    <script src="../assets/kit.js"></script>
    <style>
      /* every class and id prefixed with the scene id */
      .s06-camera { position: absolute; inset: 0; transform-origin: 960px 464px; }
    </style>

    <!-- full-bleed paper ground: a clip layer with an id, never a background on the root -->
    <div id="s06-lesson-bg" class="paper-bg clip" data-start="0" data-duration="14" data-track-index="0"></div>

    <div class="s06-camera"> ... your scene ... </div>

    <script>
      (function () {
        const S = Kit.scope('s06-lesson');          // scoped queries: S.q('.x'), S.qa('.x')
        const tl = gsap.timeline({ paused: true });  // ONE paused timeline
        // ... Kit helpers and tl.to/fromTo/set at LOCAL times ...
        tl.set({}, {}, 14);                          // pin the timeline length to the scene duration
        window.__timelines = window.__timelines || {};
        window.__timelines['s06-lesson'] = tl;       // key = composition id = scene id
      })();
    </script>
  </div>
</template>
```

Rules:

- `data-composition-id` = scene id = file name = key in `window.__timelines`.
  `data-duration` = `end - start` from `script.json`.
- **Local time.** Your timeline runs in scene-local seconds: 0 is the scene's `data-start`.
  Verified: a tween at local 0..4 in a scene mounted at film 2 s was exactly 25% done at
  film 3 s. Film time = scene start + local time (needed only for SFX cues and snapshots).
- Build the timeline synchronously in the scene script (no `setTimeout`, no `await`,
  no `requestAnimationFrame`, no `Date`, no `Math.random`; use `Kit.rng(seed)`).
- No CSS `transition` or `@keyframes` animation. Everything goes through the timeline.
- **All scenes share one document.** Unprefixed classes and ids collide. Prefix everything
  with your scene id (`.s06-board`, `#s06-arrow`). Kit classes (`.leaf`, `.stamp`...) are the
  only shared names. Never style a kit class globally in your scene; add your own modifier.
- Do not style the composition root element (the `data-composition-id` div); style children.
- Content that must not appear before its entrance: use Kit entrances (they hide the element
  until its time), or `tl.set(el, {visibility:'hidden'}, 0)` + a later set. Do not rely on CSS
  `opacity:0` plus a tween; that breaks backward seeks.
- Scenes are cut by their host clip at `data-duration`; no exit animation is needed unless
  the handoff asks for one. The last frame must equal the handoff state in PLAN.md.

## 4. Kit API (assets/kit.js, `window.Kit`)

Every helper adds tweens to `tl` at an absolute LOCAL time and returns the end time.
Targets: element, array/NodeList, or selector (selectors are document-wide, so pass scoped
elements from `S.q`/`S.qa`).

| Helper | What it does |
|---|---|
| `Kit.scope(id)` | `{root, q, qa}` queries limited to your scene |
| `Kit.stepIn(tl, el, t, {y=6, x, scale, stagger, dur=0.09, hideBefore=true})` | the product entrance: opacity 0.4 to 1 + y 6 to 0, `steps(2)`; hidden before `t` |
| `Kit.stepOut(tl, el, t, {y=-4, dur=0.066})` | faster exit, then hidden |
| `Kit.hingeIn(tl, el, t, {from=-14, dur=0.18, steps=3, origin='0% 50%', perspective=1400})` | leaf hinges in from the punched (left) edge; for slips from the bottom use `origin:'50% 100%'` and animate `rotationX` yourself |
| `Kit.hingeOut(tl, el, t)` | hinge back and hide |
| `Kit.plot(tl, svgEl, t, {dur=0.72, steps=8, label, stagger})` | pen-plotter stroke draw (path, line, polyline, rect, circle); `label` steps in at half time |
| `Kit.fillIn(tl, el, t)` | stepped fill after a plotted outline |
| `Kit.typeText(tl, el, text, t, {cps=18, caret=true, caretUntil, prefix, placeholder})` | types code points at 18 chars/s with a caret; shows `placeholder` before typing |
| `Kit.deleteText(tl, el, text, t, {cps=22})` | deletes letter by letter (s02) |
| `Kit.textAt(tl, el, [[t,'1 დღე'],[t2,'3 დღე']], {html})` | stepped text swaps |
| `Kit.countTo(tl, el, from, to, t, dur, {format, ease})` | mono number ticking |
| `Kit.classAt(tl, el, cls, t, tOff=null)` | toggle a state class (e.g. `pressed`, `correct`, `dimmed`) |
| `Kit.press(tl, btn, t, {hold=0.24 or null})` | button press: invert to ink (yellow type on primary) + tiny scale |
| `Kit.makeCursor(parent, 'gio', 'გიო', {x, y})` | ink arrow + name pill in the person colour; tip at (x, y) |
| `Kit.cursorMove(tl, cur, t, x, y, {dur=0.8})` | smooth move, `power3.inOut` |
| `Kit.cursorClick(tl, cur, t, {press: btn})` | press 0.92 + ring; optional button press |
| `Kit.camera(tl, wrapper, t, {scale, x, y}, {dur=1.2, ease='power3.inOut'})` | smooth camera on a wrapper |
| `Kit.dim(tl, el, t)` / `Kit.undim(tl, el, t)` | focus economy: saturate 0.35 + opacity 0.5, stepped |
| `Kit.stamp(tl, el, t, {from=1.12})` | stamp lands from 1.12x, stepped |
| `Kit.track(tl, t0, t1, fn)` | the generic seek-safe hook: `fn(secondsSinceT0, progress)` runs on every render inside the window |
| `Kit.icon(name)` / `Kit.hydrateIcons(root)` | lucide SVG string / replace `<i data-icon="check"></i>` |
| `Kit.rng(seed)` | deterministic random for scatter |
| `Kit.STEP` | 0.09 s; `Kit.SFX` the SFX name list |

Icons available: check, arrow-up-right, arrow-left, help-circle, send, message-square, users,
book-open, layers, pen-tool, list, x, play. Ask the kit owner for more (lucide geometry only).

Example (s07 style):

```js
const S = Kit.scope('s07-triage');
const tl = gsap.timeline({ paused: true });
const gio = Kit.makeCursor(S.root, 'gio', 'გიო', { x: 1500, y: 980 });
Kit.cursorMove(tl, gio, 0.4, 820, 960);
Kit.cursorClick(tl, gio, 1.25);
let t = Kit.typeText(tl, S.q('.s07-ask'), 'რატომ ვერ აწერს PDA ხელს ტრანზაქციას?', 1.4, { placeholder: 'ჰკითხე ნებისმიერი რამ' });
Kit.press(tl, S.q('.s07-askbtn'), t + 0.2);
Kit.hingeIn(tl, S.q('.s07-card-gio'), t + 0.4);
Kit.stamp(tl, S.q('.s07-card-gio .stamp'), t + 0.6);
Kit.plot(tl, S.q('#s07-route-1'), 9.0, { label: S.q('.s07-route-1-label') });
Kit.camera(tl, S.q('.s07-camera'), 12, { scale: 1.25, x: -300, y: 40 });
```

## 6. Type scale (px at 1080p)

| Role | Size | Font, settings |
|---|---|---|
| Display (title page only) | 168-200 | Archivo / Noto Sans Georgian, 850, `font-stretch: 75%`, lh 0.9, -0.02em |
| Headline | 64-80 | same stack, 800, stretch 75-78% |
| Title | 44-52 | same stack, 700-750, stretch 80-82% |
| Body / UI text | 32 | same stack, 400 (question titles 680, stretch 86%) |
| Reading (tutor speech, captions, notes, answers) | 32-40 | Source Serif 4 / Noto Serif Georgian, 400-500 |
| Label, stamp, button | 28-30 | Archivo stack, 650-750, stretch 78-88% |
| Mono (numbers, codes, times, keys) | 28-64 | JetBrains Mono |
| Subtitles (layer, not yours) | 40 | Noto Serif Georgian 500 |

Minimum on-screen text is 28 px, except text inside a recreated UI that the camera shows
at less than 1x on purpose. Max about 8 words per block outside UI recreations.
Georgian follows the width axis: use `font-stretch` (75%-100%), not `font-variation-settings`.

### Mtavruli (uppercase Georgian): decision

Verified: `text-transform: uppercase` does **not** change Georgian in Chrome (Mkhedruli stays
as is); explicit Mtavruli code points (U+1C90-1CBF) do render in both Noto faces, no tofu.
Decision: Georgian labels, stamps, tabs and buttons stay in normal case (Mkhedruli), which is
how Georgian UI reads; `.label`, `.stamp`, `.btn`, `.tab-title` keep `text-transform:
uppercase` only for their Latin text (CHALKROOM LIVE, PDA, Hacktoberfest) and use tracking
0.05em, which suits both scripts. Latin-only labels can add `.lat` (0.14em). Do not type
Mtavruli by hand.

## 7. Safe area and layout

- Frame 1920 x 1080. Side margins 80 px. Keep all important content above y = 910
  (the bottom 170 px are the subtitle band). The subtitles sit 54 px from the bottom,
  max 1400 px wide, up to two lines.
- Rest centre of the content area is (960, 464); use it as the camera origin
  (`transform-origin: 960px 464px` on your camera wrapper).
- Never `transform` (CSS) an element that GSAP animates; GSAP owns `transform`. Centre with
  `left/right/margin` or put the static transform on a wrapper (s04 stamp: rotated wrapper,
  scaled child).
- Intentional off-frame or overflowing parts get `data-layout-allow-overflow`; intentional
  layering gets `data-layout-allow-occlusion`, so `check` stays clean.

## 8. Motion rules (from PLAN.md)

1. UI state changes step: two frames, 90 ms, `steps(2)` (stamps, presses, punches, swaps).
   Leaves hinge in from the punched edge.
2. Board figures plot on in `steps(8)`; labels at half the stroke time. The film's signature.
3. The camera is smooth: `power3.inOut` / `expo.inOut`, 0.8-1.6 s. Pull back to reveal scale.

No bouncy easing, no particles, no lone fades (entrances move 2-3 properties). Stagger lists
0.08-0.15 s. Exits faster than entrances. Anything on screen over 2 s gets secondary motion;
never more than 3 s without a new event. Yellow only on the one pressable action; vermilion
only for problems and wrong answers. Cursors type at about 18 chars/s. Time beats to the
voice: read the cue times in `script.json` (cue start = when the word starts).

## 10. SFX cue files

Scenes never contain `<audio>`. Each scene ships `audio/cues/<sceneId>.json`:

```json
{
  "scene": "s04-reveal",
  "start": 30,
  "cues": [
    { "t": 30.30, "name": "paper" },
    { "t": 32.75, "name": "stamp" }
  ]
}
```

`t` is in FILM seconds (scene start + local time), sorted. Names (fixed list):

| name | use |
|---|---|
| paper | a leaf or slip moves, slides, hinges |
| stamp | a status stamp lands, a tab flicks |
| plot | a board stroke plots (one per stroke group) |
| key | one per typing burst start (the audio pass spreads key clicks over the burst; add `"dur"` in seconds) |
| pop | a punch (person) joins |
| chime | correct / answered |
| click | cursor click, button press |
| thud | a vermilion problem beat |
| whoosh | a big camera move (use sparingly) |
| swap | a stepped content swap, a line printing |

Optional fields: `"dur"` (for key bursts), `"gain"` (in dB, e.g. -6; default 0; this is what tools/audio/mix_sfx.py reads).

## 11. Audio in index.html

`audio/music.wav` is mounted. `audio/sfx.wav` is commented out until it exists: a missing
audio file is a lint error (`audio_src_not_found`) and fails `check`. Uncomment it once the
audio pass delivers it. The voice slot (`audio/voice.wav`) is commented for the same reason.

## 12. Gotchas (all hit and verified)

- **Fonts per file.** `lint` checks each composition file for `@font-face` of every family
  it names. Linking `../assets/chalk.css` inside the template satisfies it. Never name a font
  that is not in chalk.css (no system fonts at render time).
- **Paths.** Use `../assets/...` inside scene files (relative to `compositions/`).
- **Mono plus Georgian.** JetBrains Mono has no Georgian; "3 დღე" in `.mono` falls back for the
  Georgian part and the space is mono-wide. Wrap the Georgian words in a non-mono span.
- **Entrances hide.** `stepIn`, `hingeIn`, `stamp`, `plot` hide their target from 0 until `t`.
  For a second entrance of the same element, pass `{hideBefore:false}` or animate it yourself.
- **One state toggle per element and class.** Do not call `classAt` twice for the same
  element and class; use one call with an on and off time.
- **Seek safety.** Verified seek-safe (forward and backward, out of order): x/y/scale,
  `steps()` eases, `strokeDashoffset`, `attr` tweens, `rotationY` with `transformPerspective`,
  `filter: saturate()`, `clipPath: inset()`, `visibility` sets, `onUpdate` text (Kit.track).
  Text changes must go through Kit helpers (`track`), never through callbacks like `onStart`.
- **Lint wants an id** on timed elements (`studio_missing_editable_id`): give your
  `.paper-bg clip` an id like `s06-lesson-bg`.
- **check with --range** and `--caption-zone` fails ("no caption-zone samples in range"); use
  `--caption-zone "x0=0;y0=.843;x1=1;y1=1;seek=.25"` on a full check only. Subtitle cues are
  marked `data-layout-allow-caption-zone`.
- **Memory.** One Chrome command at a time. `check` and `snapshot` each take 10-15 s here.

## 13. Classroom shell

`Kit.classroom(rootEl, opts)` builds the product's class layout (`docs/pitch/img/board.png`)
in Georgian. Used by s06, s07, s08, s09, s10 so every scene frames the same room. Files:
`assets/classroom.css`, `assets/classroom.js` (owner: the s05/s06 builder). Include, inside
your template, after chalk.css and kit.js:

```html
<link rel="stylesheet" href="../assets/classroom.css" />
<script src="../assets/classroom.js"></script>
```

### Canvas and camera

The shell is laid out on a fixed **2560 x 1240 canvas** (canvas px) inside a camera wrapper
`cr.cam` (`transform-origin: 0 0`; GSAP owns its `x`, `y`, `scale`). A canvas point (cx, cy)
lands on screen at `(cx * scale + x, cy * scale + y)`. Mount it in a full-frame div of your
scene: `const cr = Kit.classroom(S.q('.s07-cr'), { ... })`. Class names starting `cr-` are the
shell's; do not use that prefix in scenes. Text is kit size on the canvas (28 px and up), so
the whole room at 0.71x is a UI recreation shown below 1x on purpose; push in for reading.

| Box (canvas px, x y w h) | What |
|---|---|
| `masthead` 0 0 2560 150 | brand CHALKROOM LIVE, class title, segment line, phase stamp, "ხმა ჩართულია" |
| `binding` 0 150 150 980 | punches ანა (H tab), ნიკა, გიო, მარი, open dashed seat, "4/5 აქ" |
| `stage` 150 150 1680 980 | board + caption |
| `board` 220 190 1540 747 | the board leaf (1320:640 aspect); board-local px = canvas - (220, 190) |
| `caption` 220 968 1540 120 | serif caption line under the board |
| `lesson` 200 170 1580 940 | board + caption (a framing box) |
| `rail` 1830 150 620 980 | right rail: tabs "კითხვები" / "ჩანაწერები" at y 172-242 |
| `railList` 1854 262 580 850 | container for question cards (`.q-card` is 580 wide inside it) |
| `tabs` 2460 150 100 980 | fore-edge tabs: "რა არის PDA?" orange (y 160-396), "bump-ის პოვნა" teal (406-656), "ხელმოწერა invoke_signed-ით" grass (666-1120) |

Named views (`cr.view(name)` returns `{scale, x, y}` for `cr.cam`):

| View | scale, x, y | Use |
|---|---|---|

| `device` | 0.75, 0, 75 | whole room centred in a 16:9 frame (device screens in s06) |

| `board` | 1.13788, -166.51, -176.20 | board alone |
| `rail` | rail box fitted into the inset (0.867x) | |

(`'inset'` default = 80,40 1760x850; `'safe'` = 0,0 1920x885; `'frame'` = full frame; or your
own `{x,y,w,h}`).

  page: 'გვერდი 1',              // board page number
  caption: '',                  // caption text under the board
  currentTab: 'orange',         // which fore-edge tab is current (ink edge)
  tabTimes: { orange: '0:30', teal: '~3წთ', grass: '~3წთ' },
  railTab: 'questions',         // or 'notes'
  punches: { nika: { thread: true }, gio: { ready: true }, mari: { away: true, hidden: false } },
